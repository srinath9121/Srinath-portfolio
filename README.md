# M Srinath Swamy — Personal Portfolio

Personal portfolio for **M Srinath Swamy** — Data Science student focused on AI/ML engineering, research, and practical technical systems. Built with Next.js 15, TypeScript, Tailwind CSS v4, and MDX.

![Portfolio preview](./public/assets/readme-preview.png)

**Site:** [nathos.dev](https://nathos.dev) · **GitHub:** [@srinath9121](https://github.com/srinath9121)

---

## Featured Work

- **Indian Macro Terminal** — An Indian macroeconomic and market intelligence workstation.
- **Solar PV Ramp Detection** — Multimodal deep learning for early warning of severe solar power ramp events using fisheye sky-camera images and photovoltaic (PV) time series.

---

## Highlights

- **Home** — hero, tech stack, featured projects, GitHub contributions, quote & visitor card
- **About** — narrative background and engineering principles
- **Projects** — project showcase with MDX long-form writeups and tech stack tags
- **Work** — roles, technical systems, and experience timeline
- **Blog** — research notes and articles
- **Books & Favourites** — curated cultural and literary influences
- **Resume** — embedded document viewer and contact download
- **Command palette** — search any page with `⌘K` / `Ctrl+K`
- **Theme toggle** — light / dark mode
- **Aizen** — animated cursor pet (Black Raven) with 8-directional flight

## Getting Started

**Requirements:** Node.js 18+

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm start` | Run production server |
| `npm run lint` | Run ESLint |
