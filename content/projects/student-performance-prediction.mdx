## Project Overview

An end-to-end machine learning project that predicts students' final grades using demographic, academic, family, and social factors.

## Dataset

- **Source:** [UCI Machine Learning Repository — Student Performance](https://archive.ics.uci.edu/dataset/320/student+performance)

## Repository

- **GitHub:** [https://github.com/srinath9121/Analysis-on-Student-grade-Prediction-using-ML](https://github.com/srinath9121/Analysis-on-Student-grade-Prediction-using-ML)

## Methodology

1. **Exploratory data analysis and visualization**
2. **Missing-value handling**
3. **Categorical encoding and numerical feature scaling**
4. **Comparison of Linear Regression, Ridge, Lasso, SVR, Random Forest, Gradient Boosting, XGBoost, and an artificial neural network**
5. **Model evaluation and analysis of influential features**

## Technologies Used

- Python
- scikit-learn
- XGBoost
