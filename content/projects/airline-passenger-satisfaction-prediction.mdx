## Project Overview

An end-to-end machine learning project that predicts airline passenger satisfaction using demographic information, travel details, service ratings, and flight delay data.

## Dataset

- **Source:** [Kaggle — Airline Passenger Satisfaction](https://www.kaggle.com/datasets/mysarahmadbhat/airline-passenger-satisfaction)

## Repository

- **GitHub:** [https://github.com/srinath9121/Analysis-on-Airline-Passenger-Satisfaction-Prediction-using-ML](https://github.com/srinath9121/Analysis-on-Airline-Passenger-Satisfaction-Prediction-using-ML)

## Methodology

1. **Exploratory data analysis and visualization**
2. **Missing-value handling and categorical encoding**
3. **Numerical feature scaling**
4. **Class-imbalance handling using SMOTE**
5. **Comparison of Logistic Regression, Random Forest, Gradient Boosting, XGBoost, SVM, and KNN**
6. **Model evaluation and feature-importance analysis**

- Python
